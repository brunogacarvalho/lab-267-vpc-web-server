Documentação prática do laboratório de criação de uma VPC e configuração de um servidor web na nuvem.

Lab 267 Amazon VPC Amazon EC2
01

Sobre o laboratório

Objetivo e atividades realizadas

O objetivo deste laboratório foi criar uma rede virtual na AWS, configurar sub-redes públicas e privadas e disponibilizar uma aplicação web por meio de uma instância Amazon EC2.

Durante a atividade, foram configurados componentes de rede, regras de acesso e um script de inicialização para preparar o servidor web automaticamente.

02

Recursos utilizados

Principais componentes do laboratório

01

Amazon VPC

Rede virtual isolada que reúne os recursos e define o espaço de endereços IP utilizado.

10.0.0.0/16
02

Sub-redes e rotas

Divisão da rede em sub-redes públicas e privadas, com tabelas de rotas para direcionar o tráfego.

4 sub-redes
03

Internet Gateway

Componente que permite a comunicação entre a VPC e a internet, conforme as rotas e regras configuradas.

Conectividade externa
04

NAT Gateway

Permite que recursos em sub-redes privadas iniciem conexões com a internet sem receber conexões diretamente da internet por esse caminho.

Saída para a internet
05

Security Group

Controla o tráfego permitido para a instância. Neste laboratório, foi configurada uma regra para acesso HTTP.

TCP · Porta 80
06

Amazon EC2

Instância virtual utilizada para hospedar a aplicação e disponibilizá-la pelo endereço público.

Web Server 1 · t3.micro
03

Configuração do servidor

Inicialização automatizada com User Data

Na criação da instância EC2, foi utilizado um script de User Data para preparar o ambiente automaticamente.

  • Atualização dos pacotes do sistema.
  • Instalação do Apache, PHP e unzip.
  • Download e extração dos arquivos da aplicação do laboratório.
  • Ajuste das permissões dos arquivos do site.
  • Habilitação e inicialização do serviço Apache.

O User Data executa comandos de inicialização na instância, reduzindo a necessidade de configuração manual do servidor.

O que aprendi

Conceitos praticados na atividade

  • Organização de uma rede virtual utilizando Amazon VPC.
  • Diferenças entre sub-redes públicas e privadas.
  • Uso de tabelas de rotas, Internet Gateway e NAT Gateway.
  • Controle de acesso à instância por meio de Security Groups.
  • Inicialização de um servidor web com User Data.
  • Verificação do funcionamento de uma aplicação hospedada em EC2.
